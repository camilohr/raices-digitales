# 🌱 Raíces Digitales

## Plataforma web inteligente para el fortalecimiento de competencias digitales en comunidades rurales

---

### 📋 Descripción

**Raíces Digitales** es un prototipo de plataforma web diseñado para fortalecer las competencias digitales de habitantes de comunidades rurales en el sur del departamento del Huila, Colombia.

El proyecto se desarrolla como parte del curso **Proyecto de Grado** del programa de **Ingeniería de Sistemas** de la **Universidad Nacional Abierta y a Distancia (UNAD)** .

---

### 🎯 Objetivos

#### General
Diseñar e implementar un prototipo de plataforma web inteligente que fortalezca las competencias digitales mediante rutas de aprendizaje personalizadas.

#### Específicos
1. ✅ Diagnosticar necesidades y nivel de competencias digitales
2. ✅ Diseñar arquitectura e interfaz de usuario
3. ✅ Implementar prototipo funcional con tecnologías web
4. ✅ Validar funcionamiento y usabilidad del prototipo

---

### 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| HTML5 | Estructura de páginas |
| CSS3 | Estilos y diseño responsivo |
| JavaScript (ES6+) | Lógica de la aplicación |
| localStorage | Almacenamiento de datos persistente |
| Font Awesome | Iconografía |
| Google Fonts (Inter) | Tipografía |
